# Dataset for "Using Emojis to Uplift Emotion: Effects on Mental Health Chatbots’ Performance"

## Description
This repository contains the data and analysis materials for the empirical study "Using Emojis to Uplift Emotion: Effects on Mental Health Chatbots’ Performance".

## Contents
- `data/`: Dataset files
- `README.md`: Project description

## Study Information
- Sample size: N = 459 (59 for pretest, 400 for main study)
- Data type: experiment
- Collection period: 2025-05~2025-07
- Variables

| Variable | Description |
| ----- | ----- |
| Emoji | Emoji = 1 if the participant is in the treatment group |
| PW | Perceived warmth |
| PC | Perceived competence |
| PO | Psychological ownership |
| EW | Emotional well-being |
| SA | Satisfaction |
| UI | Continuance usage intention |
| AW | Awareness of mental health chatbots |
| NT | Attitudes toward new technologies |
| HM | Self mental health management |
| AIL | Artificial intelligence literacy |
| Gender | Gender = 1 if the participant is male |
| Age | Age = 1 if the participant is over 40 |
| Edu | Edu = 1 if the participant has received higher education |
| Online | Online = 1 if the participant spend over 6 hours online per day |
| MHth | MHth = 1 if the participant believes their mental health is above average |
| Exp | Exp = 1 if the participant has used mental health chatbots more than 3 times |
